# PepTalk · Clinical Peptide Intelligence & Masterclass Academy

A modern, high-precision clinical peptide intelligence web application built with **Next.js (App Router)** and **100% TypeScript**.

---

## ⚡ Tech Stack
- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript 5 (Strict Static Typing)
- **Styling:** Modern Nexora Light System (`globals.css`)
- **Icons:** Lucide React
- **Hosting:** Vercel (Zero-Config Deployment)
- **AI Integration:** Google Gemini API with Client-Side RAG Engine

---

## 🔬 Core Features
1. **Clinical AI Chat & RAG:** Grounded clinical search across compounds, protocols, and 75 masterclasses with Google Gemini.
2. **Knowledge Base:** Over 400+ curated peptide monographs, peptide vaults, cosmetic vaults, supplement vaults, and goal stacks.
3. **Compound Monographs:** Detailed mechanisms of action, evidence-based research contexts, dosing parameters, storage, and direct PubMed citations.
4. **Vetted Protocols:** Step-by-step titration ladders, reconstitution tables, and cycle protocols.
5. **Classroom Academy:** 75 masterclasses organized by 10 clean categories with 797 accessible lessons and embedded HD video support.
6. **Syringe Calculator:** Precision reconstitution math with real-time U-100 syringe tick calculations and concentration readouts.
7. **Published Research Database:** Verified pharmacology research papers with direct PubMed and DOI links.

---

## 🚀 Getting Started

### Installation
```bash
npm install
```

### Local Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm start
```
