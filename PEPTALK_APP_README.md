# Peptalk Research Desk

## Open the app

Open `index.html` in a browser. The prototype uses plain HTML, CSS, and JavaScript and does not need a package install or build step.

## Included

- An empty compound catalog ready for source-approved records.
- A searchable index of the 797 lesson records from `Peptalk_Classroom_Archive/Lesson_Index.csv`.
- Links from each lesson record to its archived local course page and original source URL.
- Evidence-source tiers, a review-outline builder, and a comparison view that marks evidence fields as not reviewed.

`data/community-lessons.js` contains lesson titles, course/topic labels, capture status, counts, and source paths. Full lesson text remains in the original archive files; the app links to those files instead of duplicating their prose.

## Limits

- PepPal library content is not imported. Its terms restrict automated collection, copying, and use to build competing products; obtain a written license before adding it.
- The app has no live PubMed, ClinicalTrials.gov, regulator, or AI retrieval integration.
- Community archive material is unverified and must not be treated as clinical evidence.
