# PepPal data access note

I inspected the library page and one profile while mapping the product. PepPal's current [Terms of Use](https://peppal.io/terms) restrict automated collection and copying and limit the app license to personal, non-commercial use. They also prohibit using the app to create a competing product.

For that reason, no PepPal profile text, catalog dump, or library counts are included in the in-house app. The app retains only a general pointer to external evidence sources and uses the project's own local archive index.

For any future PepPal data integration, obtain written permission and a license covering internal multi-clinician use, redistribution within the organization, and any automated export or API access.
